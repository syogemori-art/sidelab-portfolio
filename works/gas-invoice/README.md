# 売上一覧から請求書を一括作成（サンプル）

> **これはサイドラボのポートフォリオ用サンプルです。** 会社名・住所・メールアドレス・口座などのデータはすべて架空です。

Google スプレッドシートにつけている「売上一覧」から、**取引先ごとの請求書 PDF をボタン1つでまとめて作る**ツールです。
Google Apps Script（GAS）で動くので、追加の費用やソフトのインストールはいりません。

---

## どんな悩みを解決するか

| よくある悩み | このツールでは |
|---|---|
| 月末に、売上一覧を見ながら請求書へ1件ずつ手で転記している | 対象の月を入力するだけで、取引先ごとに自動で集計・作成 |
| 転記ミスや消費税の計算ミスが怖い | 金額・消費税（10%）・合計を自動計算。端数処理の方法も設定で選べる |
| PDF に保存して、メールに添付して…が面倒 | PDF を月別フォルダに自動保存。PDF 添付済みの Gmail **下書き**まで作成 |
| 自動でメールが送られるのは不安 | **自動送信はしません。** 下書きを確認してから、ご自身で送信ボタンを押す方式です |

**想定例**：取引先10社の場合、毎月 約2時間かかっていた請求書作業が 約3分（確認・送信の時間を除く）に。
※数値は想定例です。取引先数や運用によって変わります。

---

## できること

- メニュー「請求書 → 今月分の請求書を作成」で、指定した月の請求書を一括作成
- 取引先ごとに売上を集計し、明細（日付・品目・数量・単価・金額）を請求書に記入
- 小計・消費税（10%）・合計（税込）を自動計算
  - 消費税の端数処理は **請求書1枚につき1回**（インボイス制度のルールに沿った方式）
- 適格請求書発行事業者の **登録番号** 欄、**振込先** 欄つきのテンプレート
- PDF を Google ドライブの「請求書PDF / 2026年11月」のような月別フォルダに保存
- （設定で ON/OFF）PDF を添付した Gmail の **下書き** を作成
- 「作成履歴」シートに、いつ・どの取引先に・いくらの請求書を作ったかを記録
- 空のスプレッドシートでもすぐ試せる、サンプルデータ作成機能つき

## 導入手順（10分ほど）

パソコンのブラウザ（Google Chrome がおすすめ）で作業してください。

### 1. スプレッドシートを用意する
1. [Google スプレッドシート](https://sheets.google.com) を開き、「空白のスプレッドシート」を作成します。
2. 左上のファイル名を「請求書ツール」など、分かりやすい名前に変更します。

### 2. プログラムを貼り付ける
1. 上のメニューの **「拡張機能」→「Apps Script」** をクリックします。新しいタブで編集画面が開きます。
2. 左側の「ファイル」にある `コード.gs` を開き、中身をすべて消してから、このフォルダの **`Code.gs` の中身をまるごと貼り付け** ます。
3. 「ファイル」の横の **「＋」→「スクリプト」** を押し、名前を `Setup` にします。中身を消して **`Setup.gs` の中身を貼り付け** ます。
4. 上の **💾（プロジェクトを保存）** ボタンを押します。

### 3. タイムゾーンを確認する（大切）
1. 編集画面の左端の **⚙（プロジェクトの設定）** を開きます。
2. 「タイムゾーン」が **「(GMT+09:00) 日本標準時 - 東京」** になっているか確認し、違っていれば変更します。
3. （任意）「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェックを入れると、左側に `appsscript.json` が出てきます。このフォルダの `appsscript.json` の中身を貼り付けると、タイムゾーンと必要な権限がまとめて設定されます。

### 4. サンプルデータを作る
1. スプレッドシートのタブに戻り、**ページを再読み込み**（F5キー）します。
2. 数秒待つと、上のメニューに **「請求書」** が出てきます。
3. **「請求書」→「初期設定（サンプルデータを作成）」** をクリックします。
4. 初回だけ「承認が必要です」と表示されます。下の「[初回の承認画面について](#初回の承認画面について)」を見ながら許可してください。
5. 許可したあと、もう一度 **「初期設定（サンプルデータを作成）」** を押すと、「売上一覧」「取引先」「請求書テンプレート」の3つのシートができます。

### 5. 自社の情報を入れる
「請求書テンプレート」シートで、**【要変更】** と書かれている部分を自社の情報に書き換えます。

| セル | 内容 |
|---|---|
| D7 | 自社名（屋号）※メールの差出人名にも使われます |
| D8・D9 | 住所・電話番号 |
| D10 | 登録番号（T＋13桁）。未登録なら空欄に |
| B32 | 振込先口座 |

※ 書き換え忘れがあると、請求書を作る前に警告が表示されます。

### 6. 請求書を作る
1. **「請求書」→「今月分の請求書を作成」** をクリックします。
2. 対象の月を聞かれます。空欄のまま OK で今月分、先月分なら「2026/10」のように入力します。
3. 作成される取引先の一覧が表示されるので、確認して OK を押します。
4. 完了画面に PDF の保存先が表示されます。Gmail の **「下書き」** フォルダも確認し、内容を確かめてから送信してください。

### 7. 実際の運用に切り替える
- 「売上一覧」「取引先」のサンプル行を消して、実際のデータを入力します（1行目の見出しは消さないでください）。
- 売上一覧の **金額** 欄は空欄でも OK です（空欄なら「数量 × 単価」で計算します）。

## 設定項目（`Code.gs` の先頭 `CONFIG`）

| 項目 | 初期値 | 説明 |
|---|---|---|
| `TAX_RATE` | `0.10` | 消費税率 |
| `TAX_ROUNDING` | `'floor'` | 消費税の端数処理。`'floor'` 切り捨て／`'round'` 四捨五入／`'ceil'` 切り上げ |
| `PDF_FOLDER_NAME` | `'請求書PDF'` | PDF を保存するマイドライブ直下のフォルダ名 |
| `CREATE_GMAIL_DRAFT` | `true` | Gmail の下書きを作るか（`false` で PDF のみ）。**どちらでも自動送信はしません** |
| `KEEP_INVOICE_SHEETS` | `false` | 請求書シートをスプレッドシートに残すか（`false` なら PDF 化後に削除） |
| `ISSUE_DATE_MODE` | `'END_OF_MONTH'` | 請求日。対象月の末日（`'END_OF_MONTH'`）か、作成した日（`'TODAY'`） |
| `PAYMENT_DUE_MONTHS` | `1` | 支払期限。`1` なら翌月末、`2` なら翌々月末 |
| `DEFAULT_HONORIFIC` | `'御中'` | 取引先シートの敬称が空欄のときに使う敬称 |
| `MAIL_SUBJECT` / `MAIL_BODY` | （文面） | 下書きの件名・本文。`{取引先}` `{合計}` などは自動で差し込まれます |
| `CELLS` / `ITEM_START_ROW` / `ITEM_ROWS` | テンプレートの位置 | 自社オリジナルの請求書レイアウトに差し替えるときに合わせます |

### シートの形式

**売上一覧**（1行目が見出し。列の順番は自由）

| 日付 | 取引先 | 品目 | 数量 | 単価 | 金額 |
|---|---|---|---|---|---|
| 2026/11/03 | 株式会社サンプル商事 | ホームページ保守（月額） | 1 | 15,000 | 15,000 |

**取引先**

| 取引先名 | 敬称 | メール | 住所 |
|---|---|---|---|
| 株式会社サンプル商事 | 御中 | keiri@sample-shoji.example.com | 〒100-0000 東京都… |

- 売上一覧の「取引先」と、取引先シートの「取引先名」は **完全に同じ文字** にしてください（全角・半角スペースの違いにも注意）。
- 取引先シートに無い名前の売上も請求書は作られますが、住所・メールが空のため下書きは作られません。

## 初回の承認画面について

初めて実行するとき、Google から「このアプリがアカウントへのアクセスを求めています」という画面が出ます。
これは **ご自身で作ったプログラムに、ご自身のデータを扱う許可を出す** ための確認です。

1. 「権限を確認」→ ご自身の Google アカウントを選びます。
2. 「**このアプリは Google で確認されていません**」と出たら、左下の **「詳細」** →「**（プロジェクト名）（安全ではないページ）に移動**」を押します。
   - 個人で作ったプログラムには必ず出る表示で、ウイルスなどの意味ではありません。
3. 許可の内容を確認して **「許可」** を押します。

| 求められる権限 | 使いみち |
|---|---|
| スプレッドシートの表示・編集 | 売上一覧の読み取り、請求書シートの作成 |
| Google ドライブのファイルの表示・作成 | PDF の保存、月別フォルダの作成 |
| 外部サービスへの接続 | スプレッドシートを PDF に変換する（Google 自身の変換機能を呼び出します） |
| Gmail のメールの閲覧・作成・送信・削除 | **下書きの作成だけに使います。** Gmail の下書きを作る機能が、Google の仕組み上この権限を必要とします。このツールがメールを送信・削除することはありません |

## 注意点

- **メールは自動送信されません。** Gmail の下書きを確認してから、ご自身で送信してください。
- **同じ月を2回作成すると**：PDF は新しいものに置き換わり、古い PDF はドライブの「ゴミ箱」に移ります（30日以内なら戻せます）。Gmail の下書きは2通目ができるので、不要な方を削除してください。
- **処理時間**：Apps Script は1回6分までしか動けません。取引先が多い場合（目安：60社以上）は5分で自動的に止まり、残りの取引先が表示されます。もう一度実行すれば続きを作れます。
- **Google の利用上限**：無料の Google アカウントでも通常の使い方で上限に達することはまずありませんが、1日に何百回も PDF を作ると、一時的に PDF 化が断られることがあります（自動で数回やり直します）。
- **Gmail の送信上限**（参考）：下書きの作成は送信回数に数えられません。送信は Gmail 側の上限（無料アカウントで1日あたり約500通）に従います。
- **登録番号**：インボイス制度の要件（登録番号・税率ごとの消費税額など）を満たすための欄を用意していますが、最終的な記載内容は税理士などの専門家にご確認ください。
- 軽減税率（8%）が混在する請求書には対応していません（カスタマイズで対応可能です）。
