売上一覧から
請求書を一括作成

月末にメニューを1回押すだけ。取引先ごとの請求書を作って PDF で保存し、PDF を添付したメールの下書きまで自動で用意します。

こんなお悩みに

毎月かならず発生するのに、手作業だとミスが起きやすい作業です。

📋

1社ずつ手で転記している

売上一覧を見ながら、請求書のひな形に日付・品目・金額を写していく作業に毎月時間がかかる。

🧮

計算ミス・宛名ミスが怖い

消費税の端数や合計の計算、別の取引先の明細が混ざるなど、ミスがそのまま信用問題になる。

📨

PDF 化とメール添付が面倒

1枚ずつ PDF で保存して、メールを書いて添付して…という作業が地味に積み重なる。

解決：ボタン1つで、全社分をまとめて作成

いつもの Google スプレッドシートに「請求書」メニューを追加します。追加の費用やソフトは不要です。

これまで
約2時間
  • 売上一覧から1社ずつ転記
  • 電卓で消費税を計算
  • PDF 保存・メール作成を10回
→
導入後
約3分
  • 月を選んで OK を押すだけ
  • 金額・消費税は自動計算
  • 下書きを確認して送信するだけ

※ 想定例：取引先10社・明細30行程度の場合。メールの確認・送信の時間は含みません。実際の効果は取引先数や運用によって変わります。

主な機能

消費税10%を自動計算

インボイス制度に沿って、請求書1枚ごとに1回だけ端数処理。切り捨て・四捨五入・切り上げを選べます。

メールは下書きまで

自動送信はしません。宛先・金額を目で確認してから送れます。下書き作成自体をオフにもできます。

書き換え忘れを警告

登録番号や振込先がサンプルのままだと、作成前にお知らせします。

作成履歴を記録

いつ・どの取引先に・いくらの請求書を作ったかを、シートに自動で残します。

途中で止まらない工夫

1社でエラーが出ても残りは続行。PDF 化が混み合ったときは自動で再試行します。

すぐ試せる初期設定

空のスプレッドシートで実行すると、架空のサンプルデータとテンプレートを自動で作ります。

コードの一部

お客様が後から読んでも分かるように、日本語のコメントを丁寧につけています（抜粋・一部簡略化）。

// --- 金額計算（消費税は請求書1枚につき1回だけ端数処理） ---
const subtotal = items.reduce(function (sum, it) { return sum + it.amount; }, 0);
const tax = roundYen_(subtotal * CONFIG.TAX_RATE);
const total = subtotal + tax;

// --- PDF を作ってドライブに保存（同名ファイルがあればゴミ箱へ移して置き換え） ---
const pdfBlob = exportSheetAsPdf_(ss, sheet, fileName + '.pdf');
trashSameNameFiles_(folder, fileName + '.pdf');
const pdfFile = folder.createFile(pdfBlob);

// --- Gmail 下書き（送信はしません） ---
if (CONFIG.CREATE_GMAIL_DRAFT) {
  GmailApp.createDraft(client.email, subject, body, {
    attachments: [pdfFile.getBlob()],
    name: issuerName,
  });
}

導入の流れ

コピー＆ペーストで導入できます。くわしい手順は README にまとめています。

  1. スプレッドシートの「拡張機能 → Apps Script」にコードを貼り付けて保存
  2. スプレッドシートを再読み込みし、メニュー「請求書 → 初期設定」を実行（初回のみ承認）
  3. 「請求書テンプレート」の発行元・登録番号・振込先を自社の情報に書き換え
  4. 月末に「請求書 → 今月分の請求書を作成」を押して、下書きを確認して送信
