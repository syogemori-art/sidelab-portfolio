Googleフォームの予約を
自動で管理

予約が入った瞬間に、一覧への記録・確認メール・カレンダー登録まで自動。ダブルブッキングは自動で見つけてお店にだけ知らせ、前日にはリマインドも送ります。

こんなお悩みに

予約が増えるほど、受付の「事務作業」が本業の時間を削っていきます。

✍️

予約のたびに転記と返信

フォームの回答を見て、表に写して、カレンダーに入れて、確認メールを書く。1件ごとにこの繰り返し。

⚠️

ダブルブッキングが怖い

同じ時間に2件入っていたことに当日気づく…。目視の確認だけでは見落としが起きます。

⏰

リマインドを忘れる

前日連絡をすると無断キャンセルが減ると分かっていても、毎日続けるのは大変。

解決：受付の事務作業を、まるごと自動に

普段お使いの Google フォーム・スプレッドシート・カレンダー・Gmail だけで動きます。予約システムの月額費用は 0円です。

主な機能

ダブルブッキング検知

同じ時間帯の確定済み予約に加え、カレンダーに手入力した私用の予定とも重ならないかチェックします。

同時送信にも強い

2件の予約がほぼ同時に届いても、ロック機能で1件ずつ順番に処理するので重複を見逃しません。

記録は必ず残る

メール送信などで問題が起きても、予約はまずシートに記録。エラーはオーナーにメールで知らせます。

前日リマインド

毎朝、翌日の確定予約のお客様へ自動送信。送信済みの人には二重に送りません。

確定・キャンセルも1クリック

行を選んでメニューを押すだけで、カレンダー登録や予定の削除まで行います。

設定はまとめて先頭に

店名・予約枠の長さ・定休日・受け入れ人数・リマインド時刻などを、コード先頭の設定欄で変更できます。

コードの一部

重複予約をチェックする部分です。日本語のコメントで、何をしているかが読めるようにしています（抜粋）。

// --- 予約管理シートの「確定」済み予約と時間が重なっていないか ---
let overlapCount = 0;
data.forEach(function (r, i) {
  if (i + 2 === selfRow) return; // 自分自身は数えない
  if (r[COL['ステータス'] - 1] !== STATUS.CONFIRMED) return; // 確定済みだけを数える
  const s = r[COL['開始'] - 1];
  const en = r[COL['終了'] - 1];
  if (!(s instanceof Date) || !(en instanceof Date)) return;
  if (isOverlapping_(b.start, b.end, s, en)) overlapCount++;
});
if (overlapCount >= CONFIG.CAPACITY_PER_SLOT) problems.push('重複予約');

/** 2つの時間帯が少しでも重なっていれば true（10:00-11:00 と 11:00-12:00 は重ならない扱い） */
function isOverlapping_(start1, end1, start2, end2) {
  return start1.getTime() < end2.getTime() && start2.getTime() < end1.getTime();
}

導入の流れ

コピー＆ペーストで導入できます。くわしい手順は README にまとめています。

  1. 予約用スプレッドシートの「拡張機能 → Apps Script」にコードを貼り付け、店名などの設定を書き換えて保存
  2. メニュー「予約管理 → サンプルの予約フォームを作成」（お手持ちのフォームを使う場合は不要）
  3. メニュー「予約管理 → 初期設定（自動実行を登録）」を実行（初回のみ承認）
  4. 「テスト予約を1件入れる」で動作確認。2回押すと重複検知も試せます
